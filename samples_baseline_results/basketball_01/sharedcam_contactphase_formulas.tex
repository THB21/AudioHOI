\section{Pipeline}

The current pipeline is:
\[
\text{SAM2 masks + CoTracker}
\rightarrow
\text{generic object observations}
\rightarrow
\text{shared-camera baseline}
\rightarrow
\text{contact-phase anchor interpolation}.
\]

\section{Notation}

For frame $t$, let the ball state in camera coordinates be
\[
T_t = (X_t, Y_t, Z_t),
\]
with projected center and radius
\[
(u_t, v_t), \qquad r_t.
\]

The observed 2D quantities are
\[
(u_t^{obs}, v_t^{obs}, r_t^{obs}),
\]
and the generic observation vector is
\[
\mathbf{o}_t = [u_t, v_t, r_t^{obs}, a_t, w_t, h_t, \rho_t, c_t].
\]

At the scene level, we define a shared support geometry
\[
S = (\texttt{support\_type}, floor_v, source, confidence).
\]

For the current basketball case, the default radius is
\[
R = 0.12 \text{ m}.
\]

The projection model is
\[
u_t = f_x \frac{X_t}{Z_t} + c_x,
\qquad
v_t = f_y \frac{Y_t}{Z_t} + c_y,
\qquad
r_t = f_x \frac{R}{Z_t}.
\]

\section{Shared-Camera Baseline}

The shared-camera stage first estimates a scene-level support definition from ball-contact event frames:
\[
S = (\texttt{support\_type}, floor_v, source, confidence).
\]

At the framework level, initialization is written as
\[
T_t^{init} \leftarrow \operatorname{InitFromObservation}(\mathbf{o}_t, K, \Pi, S),
\]
where $K$ is the camera intrinsic matrix and $\Pi$ is the object prior package.

For the current basketball instantiation, $\Pi$ is a sphere-like prior with known radius $R$, so
\[
Z_t^{init} = \frac{f_x R}{r_t^{obs}},
\qquad
r_t^{init} = \frac{f_x R}{Z_t^{init}}.
\]

Instead of using the observed image center directly for vertical initialization, we use the shared support line:
\[
v_t^{center,init} = floor_v - r_t^{init},
\]
\[
X_t^{init} = \frac{(u_t^{obs}-c_x)Z_t^{init}}{f_x},
\qquad
Y_t^{init} = \frac{(v_t^{center,init}-c_y)Z_t^{init}}{f_y}.
\]

The shared-camera objective is summarized as
\[
E_{\text{sharedcam}}
= \lambda_{\text{mask}} E_{\text{mask}}
+ \lambda_{\text{center}} E_{\text{center}}
+ \lambda_{\text{size}} E_{\text{size}}
+ \lambda_{\text{contact}} E_{\text{contact}}
+ \lambda_{\text{temp}} E_{\text{temp}}^{xyz}
+ \lambda_{\text{ztemp}} E_{\text{temp}}^{z}
+ \lambda_{\text{zb}} E_{\text{z-boundary}}
+ \lambda_{\text{zs}} E_{\text{z-slope}}
+ E_{\text{aux}}.
\]

Here:
\[
E_{\text{mask}} = \sum_t d_{\text{chamfer}}(C_t^{proj}, C_t^{obs}),
\]
\[
E_{\text{center}} = \sum_t \left[(u_t-u_t^{obs})^2 + (v_t-v_t^{obs})^2\right],
\]
\[
E_{\text{size}} = \sum_t \Big[(d_t-w_t)^2 + (d_t-h_t)^2 + (d_t-s_t)^2 + \alpha (a_t-a_t^{obs})^2\Big],
\]
\[
E_{\text{contact}} = \sum_{t \in C} (bottom_v(t)-floor_v)^2,
\]
\[
E_{\text{temp}}^{xyz} = \sum_t \|T_{t+1} - 2T_t + T_{t-1}\|^2,
\qquad
E_{\text{temp}}^{z} = \sum_t (Z_{t+1} - 2Z_t + Z_{t-1})^2.
\]

\section{Contact-Phase Anchor Interpolation}

In the refinement stage, we keep the observed 2D center fixed and optimize only the depth trajectory
\[
Z_1, Z_2, \dots, Z_T.
\]

Then
\[
X_t = \frac{(u_t^{obs}-c_x)Z_t}{f_x},
\qquad
Y_t = \frac{(v_t^{obs}-c_y)Z_t}{f_y}.
\]

This stage reads the shared support geometry from the shared-camera output but does not re-estimate the floor inside the hand-ball module.

For the current sequence, the active hand is fixed to the right hand. A coarse right-palm proxy is defined from SMPL-X joints:
\[
P_t^{\text{right-palm}}
= \frac{1}{5}
\left(
P_t^{21}+P_t^{40}+P_t^{43}+P_t^{46}+P_t^{49}
\right),
\]
and its depth is
\[
Z_{\text{hand}}(t) = P_{t,z}^{\text{right-palm}}.
\]

Let $C$ be the set of hand-contact event frames. At those frames, depth is treated as an exact anchor:
\[
Z_t = Z_{\text{hand}}(t), \qquad t \in C.
\]

We then estimate a global depth-layer correction from hand-contact events:
\[
\Delta Z
= \operatorname{median}_{t \in C}
\left(
Z_{\text{hand}}(t) - Z_t^{base}
\right),
\]
and form the shifted reference trajectory
\[
Z_t^{ref} = Z_t^{base} + \Delta Z.
\]

The anchor-interpolation objective is
\[
E_{\text{anchorinterp}}
= w_{\text{ref}} E_{\text{ref}}
+ w_{\text{temp}} E_{\text{temp}}
\]
subject to
\[
Z_t = Z_{\text{hand}}(t), \qquad t \in C,
\]
where
\[
E_{\text{ref}} = \sum_t (Z_t - Z_t^{ref})^2,
\qquad
E_{\text{temp}} = \sum_{t=2}^{T-1} (Z_{t+1} - 2Z_t + Z_{t-1})^2.
\]

This separates anchor values (hand-contact event depths) from trajectory shape (smooth interpolation between anchors).

\section{Summary}

The shared-camera baseline provides a stable scene-level trajectory by combining reprojection, size, support, and temporal smoothness. The contact-phase stage then applies a global depth alignment, anchors the contact frames to the hand depth, and smooths the trajectory between anchors.
